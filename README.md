# سوقنا 🛍️

متجر إلكتروني عربي متكامل — تسوّق أونلاين في السعودية.

## المميزات

- 🏠 صفحة رئيسية: بطل رئيسي، تصنيفات، منتجات مميزة، عدّاد عروض، آراء العملاء
- 🛒 سلة تسوق كاملة مع حفظ تلقائي + شريط تقدّم للشحن المجاني
- 💳 صفحة دفع مع عناوين وطرق دفع متعددة وشاشة تأكيد الطلب
- 🔍 بحث وفلترة حسب التصنيف والسعر والتقييم والخصومات
- 🤍 قائمة مفضلة محفوظة محلياً
- 📱 تصميم متجاوب بالكامل + دعم RTL وخط عربي

## التقنيات

Next.js 15 • React 19 • Tailwind CSS 4 • TypeScript

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000)
