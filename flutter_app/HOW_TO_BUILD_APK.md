# دليل بناء تطبيق "هيا نجمعها" بصيغة APK عبر فلاتر وأندرويد ستوديو 📱

هذا المجلد يحتوي على مشروع فلاتر (`Flutter Project`) جاهز ومتكامل مع كافة الأذونات وإعدادات لغة فلاتر ورفع الإيصالات وعرض الشاشات لدعم الهواتف والأجهزة الذكية.

---

## 🛠️ المتطلبات الأساسية على جهازك:
1. تثبيت **Flutter SDK** على جهاز الكمبيوتر الخاص بك.
2. تثبيت برنامج **Android Studio** مع تثبيت إضافة **Flutter** و **Dart**.

---

## 🚀 خطوات بناء الـ APK خطوة بخطوة:

### الخطوة 1: فتح المشروع في Android Studio
1. افتح برنامج **Android Studio**.
2. اختر **Open** ثم حدد مجلد `flutter_app`.
3. انتظر حتى يكتمل فحص الملفات (Indexing).

---

### الخطوة 2: تحميل المكتبات وحزم فلاتر
افتح الطرفية (Terminal) داخل Android Studio أو في جهازك، واكتب الأمر التالي:
```bash
flutter pub get
```

---

### الخطوة 3: بناء ملف الـ APK النهائي (Release APK)
قم بتشغيل أمر البناء التالي:
```bash
flutter build apk --release
```
*(أو لاختيار أجهزة 64-bit الحديثة فقط لتصغير حجم الملف)*:
```bash
flutter build apk --split-per-abi
```

---

### الخطوة 4: موقع ملف الـ APK الجاهز للتثبيت 📦
بعد انتهاء البناء بنجاح (خلال دقيقة أو دقيقتين)، ستجد ملف التطبيق الجاهز في هذا المسار:
```
flutter_app/build/app/outputs/flutter-apk/app-release.apk
```
يمكنك نقله فوراً إلى أي هاتف أندرويد وتثبيته مباشرة والاستمتاع بتطبيق "هيا نجمعها" كتطبيق أندرويد أصلي!

---

## 🔒 مميزات هذه النسخة في فلاتر:
- دعم كامل لرفع وتصوير إيصالات السداد عبر الكاميرا والمعرض.
- واجهة تدعم اللغة العربية من اليمين إلى اليسار (RTL).
- معالجة ذكية لحالة انقطاع الإنترنت مع زر إعادة المحاولة.
- دعم الرجوع الذكي بزر الهاتف بدون الخروج المفاجئ.
- لا توجد أي عبارات أو إشارات ظاهرة لـ "فايربيس".
